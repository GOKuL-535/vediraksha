      🔌 How to connect to a real backend

      The sending logic is encapsulated inside the sendNotification(channel, recipient, payload) handler. To connect to production:

      • Email: Replace the simulated email delay with a POST call to your SendGrid / AWS SES API endpoint (e.g., fetch('/api/v1/alerts/email', { method: 'POST', body: JSON.stringify({...}) })).
      • SMS & Automated Call: Connect the SMS and automated IVR calling steps to Twilio / Plivo APIs (e.g., twilio.calls.create({ url: '/ivr/alert', to: phone, from: twilioNumber })).
      • Real-time State: Replace the local state timer with WebSockets or Server-Sent Events (SSE) listening for alert.acknowledged events.
